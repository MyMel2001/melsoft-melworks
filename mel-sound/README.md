# MelSound

MelSound - Professional Music Production Studio (FL Studio / DAW style).

## Features
- Project model with BPM, master gain, tracks (16-step patterns), and instruments (synth/sampler/VST plugins).
- Serialize/deserialize project JSON bundles.

## Commands
- `npm start` - launch Electron app.
- `npm test` - run automated project engine checks.
- `npm run serve` - static web server for UI.

## Out of scope (by design)
- Real-time audio synthesis/playback engine (future milestone).
- Native FL Studio (.FLP) binary import/export (future milestone).
