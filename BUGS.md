# Known bugs

## MelOffice

* Most slides, especially in slideshows with media, show as "undefined" in the slide show (f5) mode.
	* they show as blank slides in the editor.
* There is no image support (yet).

## MelDraw

* There is no option to sort layers manually.
* Typing (text) tools (such as horizontal type) don't work.
* Creating new document keeps previous history
* There should be tabs of documents by default
* Open menu doesn't work.

## MelCromedia

* Marquee select tool is broken.
* Keyboard shortcuts don't work either.
